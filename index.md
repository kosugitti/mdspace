Provides various multidimensional scaling (MDS) algorithms including
classical MDS (Torgerson), nonmetric MDS (Kruskal), individual
differences MDS (INDSCAL), ellipse model (Okada-Imaizumi), HFM (Chino),
and von Mises model (Shojima). Includes an interactive Shiny application
for GUI-based analysis and visualization.
