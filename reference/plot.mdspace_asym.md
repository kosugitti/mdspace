# Plot the skew-symmetric part as a heat map

Positive cells (row \> column) are red and negative cells are blue.

## Usage

``` r
# S3 method for class 'mdspace_asym'
plot(x, ...)
```

## Arguments

- x:

  An object of class `mdspace_asym`.

- ...:

  Passed to
  [`graphics::image()`](https://rdrr.io/r/graphics/image.html).

## Value

`x`, invisibly.
