# Plot the configuration of an mdspace object

Plot the configuration of an mdspace object

## Usage

``` r
# S3 method for class 'mdspace'
plot(x, dims = c(1, 2), labels = TRUE, ...)
```

## Arguments

- x:

  An object of class `mdspace`.

- dims:

  Two dimensions to plot.

- labels:

  Logical; draw object labels.

- ...:

  Passed to
  [`graphics::plot()`](https://rdrr.io/r/graphics/plot.default.html).

## Value

`x`, invisibly.
