## モデル(スライドから読み取ったもの)

- 2次元の布置 x_i,各対象に平均方向 μ_i・集中度 κ_i・総量 ω_i
- θ_ij = x_i から x_j を見た方向の角度,δ_ij = ||x_i − x_j||
- 一般化した vM 密度: f(θ | μ, κ, ω) = ω exp{κ cos(θ − μ)} / I_0(κ)(ω = 1/(2π) で通常の vM)
- π_ij = f(θ_ij | μ_i, κ_i, ω_i)(s.t. π_ij < 1)
- モデル: ξ_ij = (1 − π_ij) δ_ij ＝ i の片思いの向きにいる j ほど i から見て近くなる
- データ g_ij は非類似度(小さいほど好き)。対角は 0

### ストレス
- 2011 版: S(X, μ, κ) = Σ_{i≠j} (g_ij − ξ_ij)^2(計量・正規化なし)
- 2012 版: S(X, μ, κ, ω) = Σ_{i≠j} (g_ij − ξ_ij)^2 − U(X, μ, κ)
  - U = Σ_i Σ_{j≠i} max(g_ji − g_ij) f(θ_ij | μ_i, κ_i, 1/(2π))
  - 「片思いの相手がいる向きに密度が厚いとごほうび，いない向きに厚いとペナルティ」
  - max(g_ji − g_ij) は max(g_ji − g_ij, 0) の意と読む(i → j の片思いの度合い)
- 最適化: GA で近傍へ → 最急降下法
- 2012 の抄録には「座標の退化を防ぐ関数」も足したとあるが，スライドには式が出ていない

### 作者が挙げた今後の課題(2012)

## 試作の結果(2026-11-18)

### optim 版(`develop/20261118_vonmises_try.R`・関数は `develop/vonmises_functions.R`)
- pi_ij = c_i exp{kappa_i (cos(theta_ij − mu_i) − 1)} に書き直した(c_i = omega_i e^kappa / I0(kappa) = 山の高さ)。解析的勾配は数値微分と一致
- omega(c)を自由にすると千野データで退化する: kappa→0・c→1 で点を遠ざけて一律に縮める(座標が ±40)。2012 抄録の「退化を防ぐ関数」はこれへの手当てと思われる
- U(2012)は kappa→∞ でいくらでも大きくなる(vM の山が √kappa で伸びる)。kappa に上限を置いても，lambda = 1 で布置がつぶれる・発散する＝スライドの式のままでは使えない
- omega = 1/(2pi) 固定(2011 版)なら c は kappa で決まり，c < 1 から kappa < 6.5508

### Stan 版(本命・`develop/vonmises_mds.stan`・`develop/20261118_vonmises_stan.R`)
- 識別: 点1を原点に，残り N−1 点を `cholesky_factor_cov[N-1, 2]`(下三角・対角が正)。出典は Stan Reference Manual "Cholesky factors of covariance matrices"(M×N, M ≥ N)。先生が階層的多次元展開法のときに清水さんから教わった方法。清水さんの BayesRTMB にも `CF_cov` 型と `rtmb_mdu(method = "MDS")` がある(識別の仕方の記述はマニュアルに無い＝ソースか清水さんの章で確かめる)
- mu は `unit_vector[2]`，基準の3点は Torgerson 解から選んで先頭に並べ替える
- 局所解が多いので，`$optimize()` を乱数初期値10本で回し，最良の事後モードを全チェーンの初期値にする(しないとチェーンが別の山に分かれ Rhat 1.75)
- シミュレーション(n = 12, omega 固定, 誤差 SD 0.1): 布置は真値とほぼ一致(Procrustes なしでそのまま比べられる)，mu は12人中7人が 10 度以内(山がなだらかな G・L は 46〜54 度ずれるが，平均合成ベクトル長 R も 0.76〜0.78 と低く出る)，Rhat 1.00。発散が 6%
- 千野データ: omega 固定・自由ともに Rhat 1.01。自由でも事前分布(c ~ beta(2,4)・座標 ~ normal(0,1))で退化しない。LOO は自由のほうがよい(elpd 差 3.6, SE 1.0)が Pareto k が高い点あり。mu の確かさ(平均合成ベクトル長 R)は 0.15〜0.7 で，片思いの向きはあまり定まらない
- 次: 発散の手当て(非中心化・kappa の事前分布)，1〜7 の評定なら ordered_logistic で非計量版，3人・4人の例，BayesRTMB の実装と清水さんの章で識別の書き方を確かめる

### 識別の足場(2026-11-18 追記)
- 点1を原点・点2を第1軸・点3を上半面に置くのは**計算の足場**にすぎない。座標の事前分布を重心からのずれ x_i − x̄ ~ N(0, s_x²) に置けば(平行移動・回転・鏡映で不変)，足場の選び方は結果に効かない。推定後に重心を原点へ移し主軸に回して返す
- MAP(R 版)は補正不要(山の頂上は足場によらない)。MCMC(Stan 版)は回転角を積分で消す分の体積要素 a(点1から点2までの距離)が要る＝`target += log(Lx[1, 1])`
- 確認: R 版は足場を変えても負の対数事後密度が一致。Stan 版は千野データで足場 ABG と JDH の MCMC を比べ，点間距離の事後平均の差は最大 0.02(平均距離 1.05)，kappa の差は最大 0.06(Rhat 1.01・発散 1%)＝モンテカルロ誤差の範囲
- R 版と Stan の事後モードは目的関数が一致(Stan の解を R の目的関数で評価し R の optim を続けても動かない)。差は局所解の違いだけ＝初期値の本数を見直す
