## 2. モデル

布置 X(n × p)と対象への評価 v_j(中央を 0 にした評定)から，任意の点 P の誘因価を

  V(P) = Σ_j v_j / (1 + d²(P, x_j))

で決める(論文の式(1))。最適化は無い。電位の式の d を 1 + d² に代えて，対象の上で無限大にならないようにしたもの。

論文で読んでいるもの:
1. 等高線の図(誘因価 0 の線が好意・非好意の境目)
2. 3 次元の誘因価曲面(論文は格子の値を 6 次の多項式で最小二乗近似して描いた)
3. 評定と曲面の高さのずれ(表1・「垂線の長さ」): 評定と布置が噛み合わない対象を示す
4. Abelson の読み方 4 点(勾配＝緊張・丘が 2 つ以上＝非統合・対象と周りの符号の逆転＝不安定・0 の線が軸の両端を横切る)

## 3. 確かめたこと

- **表1は手元のファイルからは再現できない**(→ 夕方に再現できた。7 を参照)。広島 S4 の布置で式(1)を対象の点で計算すると高さは 0.79〜−2.85，6 次の多項式近似でも 0.74〜−2.79 で，表1の −2.85〜−3.48 とは合わない。論文の布置は 3 県の INDSCAL 共通空間なので座標が違うのが主な理由と思われる。`regression.cpp` は中央にそろえた評定からさらに 3 を引いているが，3 を引いた版でも合わない
- 照合の基準は式(1)そのもの(VB 版・千野版と同じ計算)にする
- **ずれの意味**: 対象 j の点の高さは V(x_j) = v_j + Σ_{k≠j} v_k / (1 + d²_jk)。したがって「評定 − 高さ」は**ほかの対象から来る力の和の符号を変えたもの**になる。近い対象と評定が逆向きだと大きくなる

## 4. 関数の案

```r
contour_mds(conf, ratings, center = 0, scale = c("none", "unit"),
            method = c("abelson", "idw"), grid = 101, lim = NULL)
```

- `conf`: 布置の行列か mdspace のオブジェクト(`$conf` を取る)。2 次元以上(1 次元は止める)。3 次元以上でも V は計算できるが，図は `dims = c(1, 2)` で選んだ平面の格子
- `ratings`: 長さ n のベクトル(1 人)か，人 × 対象の行列(人ごとの地図)。名前で対象を合わせる
- `center`: 評定から引く値(論文は 5 件法の中央 3)。既定は 0(引かない)
- `scale`: 布置の単位。式の 1 が長さの単位を決めるので，**布置を何倍するかで地図が変わる**(下の未決 1)
- `method`: `"idw"` は BSJ2012 の逆距離加重(重み 1/d²，対象の上では v_j)。入れるかは未決 2
- 返り値(クラス `mdspace_contour`): `conf`・`ratings`・`grid`(x, y, 人ごとの V の行列)・`height`(対象の点の高さ)・`discrepancy`(評定 − 高さ)・`call`。`stress` は無い(NULL)
- S3: `print`・`summary`(人ごとのずれの表)・`plot`(`type = "contour"` で base の `contour()`＋点と名前，`type = "persp"` で `persp()`，`person` で人を選ぶ)
- 外から使う関数 `contour_valence(object, newdata)` で任意の点の V を返すか，`predict` メソッドにする

## 5. 未決(先生に決めてもらうこと)

1. **布置の尺度**: 式(1)の 1 が単位を決めるので，同じ布置でも 2 倍に広げると山が鋭くなる。原典(論文)は INDSCAL の規準化した空間をそのまま使った。案: (a) 渡された布置をそのまま使う(原典どおり・既定)，(b) 重心からの平均二乗距離を 1 にそろえる選択肢をつける，(c) 1 + d²/h² の h を引数にする
2. **IDW を入れるか**: BSJ2012 で使っている。入れると「力の場」と「補間」を並べて見せられるが，IDW は誘因価ではなく評定の加重平均で，意味が違う
3. **曲面の多項式近似**: 論文の図4〜7 は格子の値を 6 次の多項式で近似したもの。いまは格子の値をそのまま `persp()` に渡せばよく，近似は要らないと考える(表1のずれも式(1)の値で出す)
