# 二相三元の円モデル(Okada & Imaizumi, 1997)の書き起こし

原典: Okada, A., & Imaizumi, T. (1997). Asymmetric multidimensional scaling of two-mode three-way proximities. *Journal of Classification*, 14, 195-224.(`develop/references/Okada_Imaizumi_1997_JClass14_two_mode_three_way.pdf`・git 管理外)
2026-11-17 に pp. 202-212 を画像で読んで書き起こした。式番号は原典のもの。

## モデル(2節)

- 共通の布置: 対象 j に点 x_j(p 次元)と半径 r_j ≥ 0
- ソース i(i = 1..N)ごとに
  - 対称重み w_i > 0: d_jki = w_i d_jk(2.2)
  - 非対称重み u_it ≥ 0(次元ごと): ソース i では対象 j の円が，次元 t の半軸 u_it r_j の**楕円**になる
- m_jki = d_jki − v_jki r_j + v_kji r_k(2.3)
- v_jki = z_jki^(1/2)(2.4)，z_jki = d_jki² / Σ_t ((x_jt − x_kt) / u_it)²(2.5)
  - v_kji = v_jki(j と k を入れ替えても同じ)＝方向だけで決まる係数。r_j v_jki が「j の楕円の，k の方向の半径」
  - したがって m_jki = w_i d_jk − v_jki (r_j − r_k)，v_jki = w_i d_jk / √Σ_t((x_jt − x_kt)/u_it)²
  - **nASYMS の出力(表1.14・2次元)で確認済み**: この式で計算した m が nASYMS の m と丸めの差 0.001 以内で一致(11セル・`tests/testthat/fixtures/README.md`)
- 一相二元(1987)は添字 i を外し v = 1 とした場合

## 目的関数(3節)

- S_i = √[ Σ_{j≠k} (m_jki − m̂_jki)² / Σ_{j≠k} (m_jki − m̄_i)² ](3.2)，m̄_i はソース i の m の平均(3.3)
- **S = √[ (1/N) Σ_i S_i² ]**(3.1)
- 単調回帰はソースごと(Kruskal 1964b)
- 不定性: X と r を c 倍し U と w を 1/c 倍しても同じ。w_i は自由な母数ではなく正規化(3.7)で決まる

## 手順(3.1〜3.5節・図4)

1. 初期値(3.2節): 各ソースの行列を対称化→**Torgerson (1952) の加算定数**を足す→二重中心化して内積行列→二乗和 1 に正規化→N 個の平均→Torgerson 法で X。u_it = 1，w_i = 1，r_j = 0
   - 高い次元の結果があれば，「寄与」(x の二乗和＋u の二乗和・3.7節)の大きい p 次元を取る
2. 反復ごとに
   - (a) **半径は最小二乗で更新**(3.8): LS_r = Σ_i Σ_{j≠k} [ (m̂_jki − d_jki) / v_jki − (r_j − r_k) ]² を最小化→min r = 0(3.9)。S を直接は最小化していない(計算が難しいため)
   - (b) X を最急降下で更新(刻み幅は α = 0, 0.1, 0.2 で S を評価する線形探索・Kruskal 1964b p.120)
   - (c) X を正規化(Σ_j x_jt = 0・Σ x² = n，3.4)，U を同じ倍率で伸縮。m を正規化して w を求める(3.7: ソースごとに Σ(m_jki − m̄_i)² = n となるよう u_i と w_i を同じスカラー倍)
   - (d) U を最急降下で更新
   - (e) (c) と同じ正規化
3. 収束: S ≤ 1e-5 か |ΔS| ≤ 1e-8(3.1節)

## 勾配(3.10〜3.19)

- ∂S/∂y = (∂S/∂S_i) Σ_{j≠k} [ (S_i/S_i*)(m_jki − m̂_jki) − (S_i/T_i*)(m_jki − m̄_i) ] ∂m_jki/∂y(3.10)
  - S_i* = Σ(m − m̂)²，T_i* = Σ(m − m̄_i)²(3.11, 3.12)。∂S/∂S_i = S_i / (N S)(原典は明示せず・要約者)
- ∂m_jki/∂x_lt = ∂d_jki/∂x_lt − (r_j − r_k) ∂v_jki/∂x_lt(3.13)
  - ∂d_jki/∂x_lt = w_i (x_jt − x_kt)(δ_jl − δ_kl) / d_jki(3.14)
  - ∂v_jki/∂x_ls = [ w_i²(x_js − x_ks)/V*_Tjki − (x_js − x_ks)/(u_is² V*_Sjki) ](δ_jl − δ_kl) の形(3.15・添字の読みは要確認)
  - V*_Sjki = w_i² Σ_t (x_jt − x_kt)²(3.16)，V*_Tjki = Σ_t ((x_jt − x_kt)/u_it)²(3.17)
- ∂m_jki/∂u_lt = −(r_j − r_k) ∂v_jki/∂u_lt(3.18)，∂v_jki/∂u_ls = w_i d_jki / (v_jki u_is³ Σ_s' ((x_js' − x_ks')/u_is')²) · δ_il δ_ts(3.19・要確認)
- 実装では v_jki = w_i d_jk / √V*_Tjki と書き直して微分し，数値微分で確かめるのが確実

## 標準化(3.6節)

- (3.20) Σ(m_jk − m̄)² = n(n−1)V(d_jk) + n(n−1)V(r_j − r_k)。q_s(3.23)と q_a で対称・非対称成分の平均的な大きさをそろえる(3.23 以降は p.213 を未読)

## mdspace での方針(案)

- 一相二元の circle_mds() と同じく，S を解析的な勾配と BFGS で直接最小化する(半径も含める)。w は正規化で決まるので母数にしない
- **初期値の加算定数**(Torgerson 1952)は circle_mds() の初期布置にも入れる価値がある(今の「最小値を 0 にずらす」は 20 対象 10 次元で正の固有値が足りなくなった原因)
- テスト用データ: nASYMS マニュアル 2.3 節の表1.14(10か国・2ソース)と nASYMS の出力

## 一相二元の楕円モデルへの手がかり

- 1997 年の楕円は全対象で縦横比が共通(u_it r_j)。一相二元の楕円(Okada 1988, 1990)は対象ごとに半軸 a_jt を自由に持つ形と思われる
- 方向 k の半径: r_jk = d_jk / √Σ_t ((x_jt − x_kt)/a_jt)²，m_jk = d_jk − r_jk + r_kj(1997 の 2.4・2.5 からの類推・要確認)
- 楕円 I〜III の区別は書籍(購入済み)か Okada (1990) で確かめる。nASYMS の楕円モデル(マニュアル 2.2 節・表1.19)で照合できる
