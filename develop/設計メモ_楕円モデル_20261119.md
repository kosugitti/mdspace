## 2. 「楕円 I〜III」について

本には I〜III という区別は出てこない(第3章・第4章・第5章とも)。本に出てくる楕円は自由度の大きい順に次の3つ。

1. 一相二元の楕円モデル(3.1.2): 対象ごとに半軸が自由(縦横比も対象ごと)
2. 二相三元の円モデル(3.2.2): ソース i で対象 j の半軸が u_it r_j(縦横比は全対象で共通)。**`circle_mds(list)` として実装済み**
3. より限定的なモデル(3.2.3): 半軸が r_j y_i u_t で，全ソース・全対象の楕円が相似

I〜III がこれに当たるのか，Okada (1990) の別の区別なのかは確かめられていない(Okada 1990 は Springer の有料の章)。

## 3. 提案する仕様

```r
ellipse_mds(x, ndim = 2, type = c("similarity", "dissimilarity"),
            ndim_max = ndim, nrandom = 10, maxit = 1000, reltol = 1e-10,
            seed = 1, check_orientation = TRUE, angles = c(10, 15, 20))
```

- 引数と返り値は `circle_mds()` にそろえる(一相二元のみ・行列のリストは受けない)
- 母数: 座標 X(n × p)と半軸 R(n × p)。半軸は対数で持って正に保つ(r = exp(ρ))。0 に近づく半軸は対数が −∞ に向かうので下限を置く(たとえば座標の尺度の 1e-4 倍)
- 最小化: `circle_mds()` と同じく，ディスパリティを固定した S の解析的な勾配＋optim(BFGS)。∂ρ_jk/∂x と ∂ρ_jk/∂r_jt は閉じた形で書ける
- 初期値: 5.4.4 どおり。`.circle_init()` の点の布置と半径を使い，r_jt = r_j とする。ただし `.circle_init()` は最小の半径を0にするので，半軸として使うときは小さな正の値を足す(0 だと v も勾配も0になって動かない)
- 次元の下ろし方: 式(5.23)の sq_t の小さい次元を落とす(主軸への回転はしない)
- 乱数の初期値: 既定 10 本(`circle_mds()` と同じ)。図5.3 の型の局所解を避けるため
- 正規化: 重心を原点・座標の二乗和 n・半軸も同じ比で伸縮。回転はしない
- 向きの確かめ(`check_orientation = TRUE`): 2次元以上なら，各2次元の組で半軸の布置を ±angles 度回し，R を固定して X だけ最小化した S を表で返す。半軸は2乗でしか効かないので，回して負になっても符号は無視してよい
- 返り値: `conf`，`semiaxis`(n × p)，`stress`，`niter`，`mjk`，`disparity`，`path`，`starts`，`best_start`，`converged`，`orientation`(回転した S の表)
- plot: `which = "conf"` は点と楕円(選んだ2次元の半軸で描く)，`which = "semiaxis"` は半軸の布置と対角線(図4.7・図3.4)
- テスト: 表4.4 の解が局所解であること(そこから最小化しても S がほぼ動かない)，乱数込みで 2次元の S が 0.324 以下に届くこと，表4.6 の回転の S，1次元で `circle_mds()` と同じ S，半軸がすべて等しいとき m が円モデルと同じ，勾配の数値微分との一致，欠測

## 6. I〜III の中身(千野・岡太 1996 で判明)

出典は千野・岡太 (1996). 非対称多次元尺度構成法とその周辺. 行動計量学, 23(2), 3.5節「岡太・今泉モデル」(pp.136-137。PDF は `~/Dropbox/PDFs/ChinoOkada1996_AsymmetricMDSReview_KodoKeiryogaku.pdf`)。元は Okada & Imaizumi (1984). Geometric models for asymmetric similarity data. Research Report, Rikkyo (St. Paul's) University(未入手。1987 年の論文で円モデルを「1984 年の Model IIIB」と呼んでいる)。

| モデル | 式 | 中身 |
|---|---|---|
| Model I | d*_jk = d_jk + α c(j,k,t) + β c(k,j,t) | いちばん一般的。c が対象の組と次元ごとに決まる |
| Model II | c(j,k,t) = c(j,t) ≥ 0 | c(j,t) を対象 j に付いた楕円(楕円体)の上の点との間の距離とみなす＝楕円モデル |
| Model III | c(j,k,t) = c(j) ≥ 0 | 円モデル。IIIB(α = −1，β = 1)が d − r_j + r_k(Okada & Imaizumi 1987) |

- II と III はそれぞれ α，β の符号で6つの下位モデルに分かれる。α = β = −1(または +1)は齋藤の団子モデル(対称)。α = 1，β = −1 は IIIB と同じ効果で r の意味だけが逆
- **Model I は c(j,k,t) がそのままでは自由な母数が多すぎて推定できない**(データ n(n−1) 個に対し n(n−1)p 個)。どう縛るかは 1984 年の報告書を見ないと分からない
- 書籍(2024)の楕円モデル(式 3.10)は II の B 型にあたる(m_jk = d_jk − ρ_jk + ρ_kj)

- 決めること: (a) kappa だけで縛る (b) 半軸の大きさにも上限(座標の大きさの何倍まで) (c) 罰則項 (d) 縛らず警告だけ
